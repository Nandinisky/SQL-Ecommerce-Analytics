# 🛒 SQL E-Commerce Analytics

## 📌 Project Overview

This project is a business-focused SQL analytics project built to analyze e-commerce sales data and generate actionable business insights.

The analysis focuses on customer behavior, product performance, sales trends, profitability, customer retention, and RFM-based customer segmentation.

## 🎯 Business Objectives

- Analyze overall sales performance
- Identify top-performing products and categories
- Analyze customer purchasing behavior
- Measure profitability and profit margins
- Analyze customer retention
- Segment customers using RFM analysis
- Identify areas requiring business attention

## 🗂️ Dataset

The project uses e-commerce data covering:

- Customers
- Products
- Sales transactions

The SQL script includes data preparation, cleaning, validation, analysis, and business-focused queries.

## 🛠️ SQL Skills & Techniques

- MySQL
- Data Cleaning & Validation
- Joins
- Aggregations
- GROUP BY
- CASE statements
- Common Table Expressions (CTEs)
- Window Functions
- RANK and DENSE_RANK
- NTILE
- Views
- Date & Time Functions
- Customer Retention Analysis
- RFM Customer Segmentation

## 📊 Key Analysis Areas

### Sales Analysis
- Total sales
- Sales trends
- Category performance
- Product performance

### Customer Analysis
- Customer purchasing behavior
- Customer retention
- Repeat customers
- RFM segmentation

### Profitability Analysis
- Revenue
- Cost
- Net profit
- Profit margin
- Loss-making categories

### Business Insights

The analysis helps identify high-value customers, strong and weak product categories, profitable business segments, customer retention patterns, and areas that may require management attention.
